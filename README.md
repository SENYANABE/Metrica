# Метрика — лендинг

Первая рабочая версия структуры лендинга на React, TypeScript, Vite, Tailwind CSS и shadcn/ui. Основное действие — заявка через https://t.me/MetricaEduBot. Серверная часть и сбор персональных данных на сайте не добавлены.

## Запуск

Требуется Node.js 22.12+ или 24+.

```sh
cd /workspace/Metrica
npm ci --cache /tmp/metrica-npm-cache
npm run dev -- --port 4173 --strictPort
```

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

## Что реализовано

- Первый экран с идеей «Новое измерение обучения».
- Переключение этапов «До / На / После занятия» и ссылка на существующее демо.
- Блоки помощи в работе, прогресса, первого обращения, FAQ и финального действия.
- Адаптивная навигация, доступные с клавиатуры вкладки и FAQ на Radix UI.
- Button, Tabs, Accordion из официального исходника shadcn/ui (new-york-v4), импорты адаптированы к локальному проекту. Конфигурация дальнейшего добавления компонентов — `components.json`.
- Локальные Noto Sans Display Condensed Black / Black Italic (variable width 75, weight 900) и Inter из Google Fonts; лицензии в `public/fonts`.

## Границы текущей версии

Шапка и первый экран сверстаны по концепции Figma (фрейм `1215:305`): логотип и изображения взяты из макета и лежат в `public/brand`. Остальные блоки пока остаются каркасом для согласования и с концепцией не сверены.

Описания возможностей основаны на тексте текущего лендинга, предоставленном заказчиком. ИИ, автопроверка, геймификация, доступ родителей и проведение занятия ещё не проверены в реальном продукте. До публикации нужно проверить формулировки и статус каждой функции. Не добавлены вымышленные цены, отзывы, метрики эффективности, сроки ответа или обещания бесплатного доступа.

Внешние демо, Telegram и политика открываются по исходным ссылкам. Доступность их содержимого зависит от внешних сервисов; локальная работоспособность лендинга от них не зависит.
