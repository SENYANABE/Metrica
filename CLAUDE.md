# Метрика — контекст передачи проекта

Продолжайте существующий проект, не создавайте новый с нуля. Сначала прочитайте README.md и design-qa.md.

## Цель

Лендинг платформы для онлайн-репетиторов. Основная идея бренда — «Новое измерение обучения». Главный посетитель — репетитор; пользу ученику и родителю показываем через общий учебный процесс.

Основная конверсия согласована: **оставить заявку** в Telegram https://t.me/MetricaEduBot. Не обещать бесплатный доступ, самостоятельную регистрацию или сроки ответа без подтверждения.

## Текущее состояние

Заказчик попросил начать собирать сайт на готовых блоках с библиотекой https://ui.shadcn.com/. Реализована первая версия на React, TypeScript, Vite, Tailwind CSS, shadcn/ui. Состав блоков и тексты ещё можно менять по согласованию.

Порядок: первый экран → до/на/после занятия → ИИ и проверка → прогресс, родители и геймификация → начало работы → FAQ → финальная заявка.

Вкладки, FAQ, мобильное меню и ссылки работают. Production-сборка и браузерные проверки прошли на ширинах 320, 375, 390, 768 и 1440 px. Проверки не подтверждают работу самой платформы или обработку обращения ботом.

## Визуальный источник

Третья, выбранная концепция: https://www.figma.com/design/mZpPrBvQsCESBBgfnP7K4D?node-id=1430-791.

Предыдущий исполнитель не получил доступ к изображениям Figma. Текущая версия не является проверенным воспроизведением концепции. До следующего визуального этапа изучите фрейм вместе с изображениями.

- Пластичный знак «М», объёмные учебные объекты, орбитальные линии, люди и устройства внутри фирменной формы — сверить по исходникам.
- Цвета: #025BFF, #7445F8, #44FF9C.
- Noto Sans Display Condensed Black и Black Italic для заголовков; Inter для пояснений. Локальные variable fonts уже подключены, точные параметры сверить с Figma. Не заменять шрифты без обсуждения.
- Логотип брать из исходников; сейчас в шапке текстовое название, не фирменный логотип.
- Название в тексте — Метрика без кавычек.
- Избегать композиции из одинаковых карточек и декоративных элементов без функции.

## Достоверность

Существующий сайт: https://outputs-livid-delta.vercel.app/.
Демо: https://outputs-livid-delta.vercel.app/platform-demo/?embed=1.

На исходном лендинге заявлены ИИ-помощник, автопроверка ДЗ, прогресс, геймификация и связь с родителями. Их реальная работоспособность не проверена. Различайте действующие и запланированные функции. Не придумывайте цены, отзывы, показатели эффективности, коммерческие условия или детали работы ИИ.

Следующий шаг: изучить Figma и демо, обсудить текущие блоки, затем уточнять дизайн и наполнение. Не считать макет финальным без согласования заказчика.

## Команды

```sh
npm ci --cache /tmp/metrica-npm-cache
npm run dev
npm run build
```

Приложению не нужны секреты или backend для локального запуска. Не коммитьте node_modules, dist, временные файлы или credentials.
