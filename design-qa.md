# Проверка лендинга

final result: дизайн всех блоков по концепции Figma; требует подтверждения контента (см. «Открытые вопросы»)

## Источник и подход

Визуальный мир задан третьей концепцией Figma (раздел `1430:791`) — это бриф, новое направление не выбиралось. Структура страницы утверждена заказчиком по вайрфрейму (`/wireframe/`). Правила качества взяты из скилла impeccable (pbakaus/impeccable): без надзаголовков над заголовками, одно авторское движение в блоке, фирменные выделение текста, фокус и полосы прокрутки, проверка всех ширин. Утилита скилла (`scripts/impeccable`) не запускалась: она скачивает исполняемый файл; правила прочитаны из справочных файлов вручную.

## Блоки

1. Шапка и первый экран — фрейм `1215:305`: знак «М» и плашка логотипа, заголовок капсом с курсивом у «ИЗМЕРЕНИЕ», композиция из исходных слоёв.
2. «Для кого» — три карточки ложатся стопкой при прокрутке (референс tokens.studio). Репетитор — кадр `1351:401`, в дисплей ноутбука перспективно подставлен экран интерфейса; ученик — `1215:326`; родитель — `1215:342`, фон #242B7B.
3. «Как это работает» — экран закреплён, пункты раскрываются по прокрутке с полосой прогресса (референс tokens.studio). Экраны — снимки интерфейса Метрики; пункт «ИИ-помощник» показан сюжетом `1351:185`. На ширине до 860 px — список с экранами.
4. «Шагните в новое измерение» — пять живых плиток на тёмно-синем (референс bencho.dev): проверка ДЗ перетаскиванием, звёзды, расписание, фильтр учеников, карточки родителя. Плоскость выпрямляется при входе в блок, открытые измерения считаются, после пяти появляется заявка.
5. Вопросы — узкая колонка по центру (референс bencho.dev).
6. Финал — синий экран, 3D-объекты из концепции на орбите.
7. Подвал — одна компактная строка.

Подписи с именами людей из баннеров («Мария Иванова», «Артём, 11 класс», «Александр, папа семиклассника») не перенесены: на сайте они читались бы как отзывы.

## Проверено

Headless Chromium, ширины 320, 375, 390, 768, 1024, 1280, 1440, 1920 px: нет горизонтальной прокрутки, заголовки не обрезаются, ошибок JS нет. Стопка карточек и закреплённый экран работают при прокрутке; все пять плиток открываются мышью и на телефоне, финальная плашка появляется; мобильное меню и закреплённая кнопка на телефоне работают; все кнопки «Оставить заявку» ведут на https://t.me/MetricaEduBot. При prefers-reduced-motion анимации и наклон отключены.

## Открытые вопросы

- ИИ-помощник: функции нет в интерфейсе; текст пункта взят со старого лендинга. Подтвердить, что именно он делает, или убрать пункт.
- Права на фото людей из концепции.
- Экраны интерфейса сняты с демонстрационной сборки, данные в них примерные.
